# Tracker Store Frontend

A modern and responsive productivity tracker UI built using HTML, CSS, and JavaScript.

## Features

- Responsive landing page
- Task input section
- Add task functionality
- Modern dark UI design
- Priority and deadline selection
- Dynamic task rendering

## Tech Stack

- HTML5
- CSS3
- JavaScript
